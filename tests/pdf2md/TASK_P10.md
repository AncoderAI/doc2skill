## 2. 交付物

### 2.1 文字密度门槛（杀掉文字框与纯文字糊块）

对每个图候选 bbox，用**带坐标的文字**算覆盖率：

- 文字来源优先级：**原生文本层**（经 `handles.py` 缓存句柄取词，不要重开文档）
  → 无原生文本层时用已有的 `word_boxes`（OCR 词框）
- `text_area_ratio` = （落在候选 bbox 内的词框**并集面积**）/ `bbox_area`
  - 用并集面积，不是各词框面积之和，避免重叠重复计数
- `text_char_count` = 落在 bbox 内的词的字符数合计

**丢弃规则**：`text_area_ratio >= TEXT_DENSITY_DROP` → `dropped = "text_block"`

阈值自己定，但必须满足：
- 纯文字段落/提示框（文字铺满）被丢
- **流程图、框图、带图例的曲线图不能被误伤**——它们也有文字，但覆盖稀疏

`cand.extra` 里记 `text_area_ratio` 与 `text_char_count`，
`figure_drops.items` 里每条带上触发数值。

### 2.2 阻止跨文本行的过度合并

矢量聚类现在会把整页吞成一张图（`page-0033` / `page-0046`）。

**要求**：聚类时，**被原生文本行占据的横向条带视为分隔带**，
分隔带两侧的矢量图元不得合并。

目标是把 `page-0046` 那种页面里**真正的曲线图单独切出来**，
而不是连同标题、公式、5 个表格一起打包。

### 2.3 图内 OCR 标签（打通第二路信号）

图切出来存盘后，对该 PNG 跑本地 tesseract，把结果填进 `FigureBlock.ocr_labels`
（`convert.py:715` 现在写死 `ocr_text=""`）。

- 语言沿用 `prof.ocr_lang`
- **性能**：P8 刚把整本转换从 245s 降到 9.9s，**不许因为本任务把它打回去**。
  逐图 OCR 有成本，做成 profile 开关：`fast` 可关，`accurate` 开；
  默认行为你定，但**必须实测并在报告里给出 IEC 96 页开/关两种耗时**。
- tesseract 不可用时**如实留空并记 warning**，不许静默。

## 7. 验收结果：**未通过，已回退**（2026-08-14）

### 实测（Claude 独立重跑，非实施方数字）

| 指标 | 改前 | P10 改后 |
|---|---|---|
| 图总数 | 132 | **230**（↑74%） |
| 面积中位数 | 305,582 px | 158,438 px（腰斩） |
| drops | too_small 129 | **too_small 733** / text_block 75 |
| 96 页耗时 | 16.2 s | **32.8 s**（↑105%） |

指标全面变差。**图更多、更碎、更慢。**

### 根因一：密度门槛选错了信号

`text_area_ratio` 杀的是「文字铺满」的块。但实际误收的绝大多数是
**表格与公式**——它们留白多、文字稀疏，正好落在门槛盲区，而这恰恰是
IEC 这类手册里最多的东西。实测幸存的误收：

- `page-0033-0001` 表格单元格 + LaTeX 公式（ratio 低于 0.30，溜过）
- `page-0052-0003` 公式框 `t_j = t_c + R_th × P` 加说明行（仍在）

### 根因二：分隔带只做了横向

`page-0046-0002` 里左边确实是那张真曲线图，但右边仍并着两个大表格。
横向条带把上下切开，**左右并排的内容没切**——这也是图数暴涨的来源：
整页被横切成 4 条，每条里仍混着图和表。

### 保留的部分

图内 OCR（`ocr_figure_asset` + `enable_figure_ocr` profile 开关）是独立且正确的一块，
**已保留**：`fast` 关、`accurate` 开，实测 `accurate` 下 `ocr_labels` 11/11 非空。
它是老板要求的「传统 CV 查漏」所需的第二路信号。

回退后 `fast` 完全回到基线：132 张图、16.2 s、`document.md` 逐字节相同（`8d3feb7c…`）。

### 给 P11 的教训

**不要用「文字多不多」区分图与非图。** 实测四页的矢量图元构成：

| 页 | 贝塞尔曲线 c | 斜线 | 轴对齐线 | 矩形 re |
|---|---|---|---|---|
| p33 纯表格 | 0 | 0 | 14 | 310 |
| p23 真图 | 364 | 95 | 186 | 15 |
| p52 CAUTION 框 | 0 | 52 | 42 | 113 |
| p46 含真曲线图 | 8 | 60 | 66 | 316 |

**「有曲线 = 是图」同样不可用**——流程图/框图全是矩形加直线、零曲线，
按这条会把它们全部误杀。p52 那 52 条斜线来自字形与警告图标，不是图。
